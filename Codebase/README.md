## Project Description

Population Data Visualizer is a Python-based project that analyzes and visualizes population data of different cities using Pandas and Matplotlib.

It helps calculate total population, identify the largest and fastest-growing cities, and display population growth through charts.

## Features

- Reads population data from CSV files.
- Cleans data and removes duplicate records.
- Handles missing and invalid values.
- Calculates total population for the latest year.
- Identifies the city with the largest population.
- Calculates population growth percentage.
- Identifies the fastest-growing city.
- Generates Bar Charts and Line Charts.
- Provides a menu-driven interface.

## Technologies Used

- Python
- Pandas
- Matplotlib
- CSV

## Menu Options

1. Population Summary
2. Growth and Charts
3. Exit

## How to Run

Install the required libraries:

```bash
pip install pandas matplotlib
```

Run the Python program:

```bash
python population_visualizer.py
```
